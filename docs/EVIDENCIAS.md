# Evidencias visuales

Estas capturas documentan los flujos de interfaz asociados a la guía. Fueron preparadas con el logo y recursos incluidos en el frontend del proyecto.

1. `01_inicio.png`: menú principal, propuesta de valor y servicios.
2. `02_catalogo.png`: listado, categorías, precios y acción de carrito.
3. `03_checkout.png`: datos de entrega, pago, cupón y resumen del pedido.
4. `04_admin.png`: indicadores, pedidos recientes y acceso a reportes.

Durante la sustentación se recomienda complementar estas evidencias con una ejecución en vivo del backend y la base PostgreSQL.
